# Max it Botswana Independent Demo

Responsive two-step UI based on the supplied layout. This package is a local simulation only; it does not send submissions or reference text to Telegram, an administrator, or a production database.

## Run
- Install Node.js 18+
- Run `npm install`
- Run `npm start`
- Open `http://localhost:3000`

`/health` reports the demo mode. Use sample data only. Do not enter real identity details, SMS verification codes, OTPs, PINs, or passwords. This is not an official Orange or Max it service.
