# Botswana application timer demo

Independent demonstration project. It is not affiliated with or an official service of Orange or Max it.

Page two includes a circular countdown from 30 to 0 below the non-secret application reference text box. When the countdown reaches zero, the user can retry and the timer restarts. This demo rejects PINs, OTPs, passwords, verification codes, and private SMS messages. It does not store or forward the entered text.

## Run
1. Install Node.js 20 or newer.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:10000`
