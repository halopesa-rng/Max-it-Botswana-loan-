# Max it-inspired independent demo

A front-end-only demo with separate details and text-demo pages. It does not send data to Telegram, collect authentication codes, or represent an official Orange/Max it service.

## Deploy
- Node.js 20+
- Install dependencies: `npm install`
- Start: `npm start`
- Health endpoint: `/health`

All review outcomes are simulated in the browser. Use fictional details only.
