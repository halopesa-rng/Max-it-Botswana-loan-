# Max it-style Independent Demo

A responsive, deployable UI prototype inspired by the supplied layout. It demonstrates Step 1 sample details, Step 2 fictional text submission, a waiting spinner, and three simulated admin outcomes.

## Run locally

Requires Node.js 18 or newer:

```sh
npm start
```

Then open `http://localhost:3000`.

## Deploy

Deploy as a Node web service. Build command can be left blank; start command is `npm start`. The service uses the hosting platform's `PORT` environment variable.

## Important scope

- This is an independent demonstration, not an official Orange or Max it service.
- All interaction is local in the browser. It does not send submissions to a server, database, SMS service, or Telegram.
- Use fictional sample values only. It intentionally does not collect or forward real identity numbers, payment details, passwords, one-time codes, or SMS verification codes.
- The orange logo is a text-based demo mark, not an official brand asset.
